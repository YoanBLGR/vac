# Design context — Échappée albanaise

## Audience

Une seule personne : la compagne de l’organisateur, qui ouvre l’application sur son téléphone le matin du départ pour découvrir un voyage surprise en Albanie.

## Use cases

- Vivre une révélation mémorable du voyage.
- Comprendre le fil du séjour sans lire un document dense.
- Consulter rapidement le prochain rendez-vous, les étapes d’une journée, les hôtels et les informations pratiques.
- Retrouver les informations essentielles même avec une connexion instable.
- Installer l’expérience sur l’écran d’accueil comme une application.

## Personality

Solaire, intime, aventureuse. L’esthétique emprunte au carnet de voyage éditorial et aux affiches méditerranéennes imprimées, sans basculer dans le folklore ou le luxe impersonnel.

## Experience principles

- Le secret précède l’information : écran nocturne avant la révélation, univers lumineux ensuite.
- Mobile d’abord, utilisable d’une main et avec des cibles tactiles d’au moins 44 px.
- Le programme se découvre par journées puis par moments, avec une divulgation progressive.
- Les animations marquent seulement les moments émotionnels et respectent `prefers-reduced-motion`.
- La référence de réservation n’est pas exposée dans le code client public.

## Brand voice

Solaire · intime · aventureuse

## Visual direction

- Palette : bleu minéral, vert Ionien, crème calcaire, abricot solaire et rouge corail rare.
- Typographie : Gloock pour les titres à caractère éditorial, Onest pour la lecture et l’interface.
- Motif mémorable : une ligne de route vivante qui relie le col, les plages et les villages.
- Thème : bleu nuit pour le secret, clair et chaud pour le voyage révélé.
